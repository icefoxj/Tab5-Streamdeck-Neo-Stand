# CLAUDE.md

3D-printable desk stand for an M5Stack Tab5 (landscape, top) and an Elgato Stream Deck Neo (bottom) on a 60° slope. The STL is generated by a parametric Python script. Never hand-edit the STL.

## Commands

```bash
pip install -r requirements.txt     # numpy, manifold3d, matplotlib (Python 3.13 tested)
python generate_stand.py            # -> stl/tab5_neo_stand.stl
python tools/check_fit.py           # must exit 0 before committing
python tools/render_previews.py     # -> images/*.png (about 20 s)
```

After any geometry change, run all three and commit the STL and images together with the code.

## Geometry conventions (generate_stand.py)

- Output frame: X = width (left to right seen from the front, 0 = centre), Y = depth (front to back), Z = up. The part prints upright as it sits on the desk.
- Feature frame on the slope: `u` = X, `v` = up the slope (0 = bottom edge of the Neo), `w` = out of the slope towards the user (0 = the surface the Neo rests on). `FACE` maps (u, v, w) to global, and `vw()` maps (v, w) to the side profile (Y, Z).
- The body is the side profile extruded along X, rounded with a Minkowski sum, then hollowed with `cavity()`. Tabs are added and `cutouts()` are subtracted.
- The Tab5 shelf is raised by `STEP = NEO_T - TAB5_T`, so both front faces are coplanar.
- `TAB5_MIRROR` flips every Tab5-related feature through `tab5_u()`.

## Design constraints to preserve

- **No supports:** surfaces leaning off the slope must keep a run/rise of at least `RUN_PER_RISE` (`MAX_OVERHANG` = 40° from vertical). Holes in the sloped faces go through `face_hole()`, which sweeps them vertically so their top edge is vertical instead of a bridge. The battery notch is open at the top for the same reason.
- **Nothing in front of the devices:** the user asked for both devices to be fully visible, with no bezel. Only the Neo lip (below the Neo) and the Tab5 tabs (below the Tab5) touch them.
- **Speaker:** the Tab5 grille sits on its bottom edge at x 91.5–110.5. The tabs (`TAB_X`) must stay clear of it, and `TAB5_GAP` is the vent.
- **Cables stay hidden:** they run from the face holes through the hollow body to `REAR_EXIT`.
- **Clean topology:** geometry that only touches leaves coincident vertices in the STL. Make parts cross each other with a small overlap instead (see the tab section and the `skin` offset in `cavity()`).

## Device data and where it came from

- Tab5: the official drawing and STL from https://github.com/m5stack/M5_Hardware (`Products/C145_Tab5/Structures/Tab5.stl`). In that STL the screen is at z = 0 and the back at z = −12. The assembled unit sits at y 0.9–80.9, and an exploded view is at negative y. Seen from the front, x runs left to right, so the USB-C is on the left edge (x = 0) and the battery and speaker are on the right half. `tools/devices.py` downloads the file to `.cache/`, which is gitignored. Do not commit it.
- Tab5 Kit: 26.7 mm thick with the battery, so the battery protrudes 14.7 mm (M5Stack docs).
- Stream Deck Neo: 107 × 78 × 26 mm from the official spec, with the integrated stand folded flat. It has not been measured physically. Its fixed USB-C cable leaves the middle of its back.
